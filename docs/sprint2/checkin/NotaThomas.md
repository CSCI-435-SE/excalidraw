## What is one thing you learned about the codebase or about software engineering practice?
I learned that Excalidraw’s free draw tool stores raw data points. It uses a streamline running average to filter jitter. It then uses perfect-freehand to build a pressure-shaped outline. That outline is drawn as a chain of quadratic Béziers through midpoints, and the result is filled. getFreedrawOutlinePoints() builds the outline of the stroke, which is a closed polygon that is filled in, rather than a line drawn with a fixed width. getSvgPathFromStroke() turns the polygon into an SVG path made of quadratic Bézier curves (Q). Each outline point is a control point, and each curve ends at the midpoint between that point and the next one. Because every curve starts and ends at a midpoint, the joins have no sharp corners. That path string is filled on the canvas with context.fill(new Path2D(shape)) in renderElement.ts:521 and is also used for SVG export. That is how Excalidraw’s free draw tool allows the user to draw smooth lines.
