That could also be the source of why the fills of objects changed between light and dark mode, but I still believe that was a design decision. I also learned that VS Code shows you the name of the last person who made a commit that changed the file you are working on if you are working with a git repository, which was originally confusing me as there was a random name in the bottom right hand corner of my screen.
